🌦️ Weather App with React & TypeScript
A dynamic weather application with real-time animations based on current conditions.

Demo GIF/Image

✨ Features
Real-time weather data (temperature, humidity, wind speed, pressure)

Immersive animations for different weather conditions:

☔ Raindrops for rainy days

❄️ Falling snowflakes

⚡ Lightning flashes for thunderstorms

🌪️ Dust/sand particles for arid conditions

Dynamic background gradients that change with the weather

Responsive glass-morphism UI

Error handling for invalid city searches

🛠️ Tech Stack
Frontend: React + TypeScript

Styling: CSS (animations with keyframes)

API: OpenWeatherMap

Icons: react-icons (Weather Icons + Spinners)

🚀 Getting Started
Prerequisites
Node.js (v14+)

npm/yarn

**Installation**
Clone the repo:
git clone https://github.com/your-username/weather-app.git

Install dependencies:
cd weather-app
npm install

Create a .env file in the root directory:
REACT_APP_OPENWEATHERMAP_API_KEY=your_api_key_here

Run the app:
npm start
